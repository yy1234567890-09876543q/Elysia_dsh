# Elysia_dsh 使用说明

手机上的 DSH 聊天客户端 —— 把电脑上跑的 `dsh web` 装进手机，走到哪儿都能聊。

## 📥 下载安装包

**[⬇ Elysia_dsh-v1.1.apk](https://github.com/yy1234567890-09876543q/Elysia_dsh/releases/latest)**

> Android 8.0（API 26）及以上。首次安装需要允许「安装未知来源应用」。

## ⚠️ 先读这段：安全警告

DSH 的接口**能在你的电脑上执行任意命令**。所以：

- ❌ **不要**把它直接暴露到公网（比如「装免认证插件 + 开 ngrok」这种组合，等于
  把一个**无需密码的远程控制入口**挂在互联网上）
- ✅ 只想在家/同一 WiFi 用 → 用 `adb reverse`，或干脆让 App 连 `127.0.0.1`
- ✅ 想在外网用 → 用 **Tailscale / WireGuard** 这类点对点 VPN（不产生公网入口），
  或者用下面「认证」那一节的办法，让服务器保留密码验证
- ✅ 万一必须开隧道：**一定要让 DSH 保持认证开启**（见「二、认证」）

App 本身不偷数据、不做统计上报、不存储任何密码，权限只有网络和通知。

## 一、第一次用（按顺序来）

### 1. 装 DSH
电脑上装好 `dsh`（`dsh web` 命令能跑就行）。

### 2. 连上它 —— 三条路，任选一条

| 方式 | 怎么做 | 安全性 |
|---|---|---|
| **`adb reverse`（推荐）** | USB 或无线调试连上手机后跑 `adb reverse tcp:3080 tcp:3080`，App 里填 `http://127.0.0.1:3080` | 🟢 只有你这台手机能连 |
| **局域网** | App 里填 `http://电脑IP:3080`（需要 `dsh web --host 0.0.0.0`，**当前版本不支持**） | — |
| **ngrok 隧道** | 见「三、ngrok 隧道」 | 🔴 **必须先看「二、认证」** |

### 3. 配置 ngrok authtoken（只在用隧道时需要）
**双击 `配置ngrok.bat`**，然后：
1. 打开 https://dashboard.ngrok.com/get-started/your-authtoken
2. 复制你页面上那串 token
3. 粘贴到命令行里，按回车
4. 看到 `Done!` 就配好了

## 二、认证（v1.1 新增，用隧道时**必看**）

DSH 默认就带认证：`dsh web` 启动时会打印一条**带令牌的地址**，用它换一张
**30 天有效**的签名凭证，之后所有请求都要带上这张凭证。

App 从 v1.1 开始原生支持这套流程，**所以你不需要再装 `dsh-local-no-auth`
那种「关掉认证」的插件了**。

### 怎么用（超简单）

1. 在跑 `dsh web` 的那个窗口里，找到这一行：

```
dsh web: http://127.0.0.1:3080/?token=Xk9vQ2m...
```

2. **把整条地址（连 `?token=` 一起）复制**
3. App → 设置 → 「DSH 服务地址」→ 粘贴 → 点「保存并连接」

App 会自动：
- 拿这个令牌去换一张 30 天有效的凭证
- 把**干净的地址**（`http://127.0.0.1:3080`）存进历史 —— 不会塞一堆一次性令牌

设置页会显示认证状态：

| 状态 | 含义 |
|---|---|
| 🟢 已认证 | 一切正常 |
| 🟡 服务器不要求认证 | 服务端没开认证 —— **确认它只对本机开放**（或者你装了免认证插件） |
| 🔴 需要令牌 | 缺凭证 —— 把带 `?token=` 的地址重新粘一次 |
| ⚪ 连不上 | 服务器没起来 / 地址填错了 |

> 💡 令牌每次 `dsh web` 重启都会变，但**换来的凭证 30 天有效**，
> 所以正常情况下一个月才需要重粘一次。

### 想彻底安全：把免认证插件卸掉

如果你装过 `dsh-local-no-auth`，建议卸掉它，让认证重新生效：

```bash
dsh plugin --profile web remove dsh-local-no-auth
```

然后**重启 `dsh web`**，复制新的带令牌地址，按上面的步骤在 App 里粘一次即可。

## 三、每次用（三步走）

### 第 1 步：启动 DSH 服务
```bash
dsh web
```
正常会看到 `dsh web: http://127.0.0.1:3080/?token=...`。

> 想用 `adb reverse` 的方式（更安全）：
> `adb reverse tcp:3080 tcp:3080`，App 里填 `http://127.0.0.1:3080` 即可。

### 第 2 步：启动 ngrok 隧道（可选）
**双击 `启动隧道.bat`**。

启动后会看到一行：
```
Forwarding  https://xxxx.ngrok-free.dev -> http://localhost:3080
```
复制那个 `https://xxxx.ngrok-free.dev` 地址。

> ⚠️ **开隧道之前，请确认「二、认证」已经配好**，否则等于把电脑的控制权公开。

### 第 3 步：连 APP
1. 打开 APP → 右上角设置
2. 「DSH 服务地址」粘贴地址
   - 走隧道：粘 ngrok 地址
   - 走 adb reverse：粘 `dsh web` 打印的**整条带 token 的地址**（认证要用）
3. 点「保存并连接」
4. 顶部会加载会话列表，选一个会话就能聊天了

## 五、常见问题

**Q: 连不上 / 502 / 浏览器警告页**
- 确认 `dsh web` 在跑
- 确认 `启动隧道.bat` 没关
- ngrok 地址别带 `/` 结尾

**Q: 提示「服务器要求认证（401）」/ 界面显示 🔴 需要令牌**
- 说明服务端开着认证，但 App 手里没有凭证
- 去设置里把 `dsh web` 打印的**整条地址（带 `?token=`）**重新粘一次就好
- 每次 `dsh web` 重启令牌都会变，但换来的凭证能用 30 天

**Q: 显示 🟡 服务器不要求认证**
- 服务端没开认证（多半装了 `dsh-local-no-auth` 之类的插件）
- **如果这个端口能被外部访问，请立刻关掉它或卸掉插件** —— 见开头的「⚠️ 安全警告」

**Q: 发消息没反应**
- 检查地址对不对
- 检查 ngrok 隧道还活着（那个黑窗口没关）

**Q: 启动隧道报错 `authtoken` 不对**
- 重新双击 `配置ngrok.bat`，粘贴正确的 token

**==Q: 通知没声音**==

- ==手机设置 → 应用 → Elysia_dsh → 通知 → DSH 任务完成 → 声音，确保开了==
- ==确认手机没开静音/勿扰模式==

**Q: ngrok 地址每次都变？**

- 免费版每次启动地址都不一样，每次都要重新复制粘贴
- 想要固定地址得买 ngrok 付费版
