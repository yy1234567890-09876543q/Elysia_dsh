# Elysia_dsh 使用说明

手机上的 DSH 聊天客户端 —— 把电脑上跑的 `dsh web` 装进手机，走到哪儿都能聊。

## 📥 下载安装包

**[⬇ Elysia_dsh-v1.0.apk](https://github.com/yy1234567890-09876543q/Elysia_dsh/releases/latest)**

> Android 8.0（API 26）及以上。首次安装需要允许「安装未知来源应用」。
> Android 13 及以上第一次打开会问通知权限，**要允许**，不然收不到「回复完成」提醒。

## ⚠️ 先读这段：安全警告

DSH 的接口**能在你的电脑上执行任意命令**。ngrok 会把 `dsh web` 的端口**暴露到公网**，
所以有两件事必须记住：

- ✅ **必须让 DSH 保持认证开启** —— 这是唯一的门锁。配好「二、认证」之后，
  别人就算拿到了你的 ngrok 地址，没有令牌也进不来。
- ❌ **绝对不要**为了图方便去装 `dsh-local-no-auth` 这类「关掉认证」的插件再开隧道，
  那等于把一个**不用密码就能控制你电脑的入口**挂在互联网上。
- 🔒 隧道那个黑窗口**用完就关**，关掉窗口 = 隧道立刻断开，外面就找不到你了。
- 🧯 万一怀疑地址泄露了：关掉隧道 + 重启 `dsh web`，旧令牌立刻作废。

App 本身不偷数据、不做统计上报、不存储任何密码，权限只有网络和通知。

## 一、第一次用（按顺序来）

### 1. 电脑上装好 DSH

在电脑上装好 `dsh`，然后开个黑窗口（按 `Win + R`，输入 `cmd`，回车），跑这条命令：

```bash
dsh web
```

看到下面这样的输出，就说明服务起来了：

```
dsh web: http://127.0.0.1:3080/?token=xxxxxxxxxxxxxxxx
```

> `token=` 后面那串就是「钥匙」，**别截图发给别人**。
>
> 看到之后先按 `Ctrl + C` 把它关掉，等下面两步弄好再重新开。

### 2. 配置 ngrok（只做一次：注册 + 填通行证）

**ngrok 是干什么的？** 一句话：它在你的电脑和手机之间**打一条小隧道**，
让手机在外面（用 4G / 5G 也行）能访问到电脑上的 `dsh web`。

项目里已经自带 `ngrok.exe`，你只需要给它一张「通行证」（authtoken）。这个只要做一次。

#### ① 注册一个免费 ngrok 账号

用浏览器打开 👉 https://dashboard.ngrok.com/signup

用邮箱注册就行（也可以直接点 Google / GitHub 登录）。免费版完全够用。

#### ② 复制你的 authtoken

注册完登录，打开 👉 https://dashboard.ngrok.com/get-started/your-authtoken

页面上有一栏写着 **Your Authtoken**，下面是一串很长的字母数字，
点它右边的**复制按钮**（通常是个小方块图标）。

> 它长得像 `2abcDEFghi...xyz`，几十个字符长。
> ⚠️ 这串东西**相当于你 ngrok 账号的密码**，不要发给任何人。

#### ③ 双击项目里的 `配置ngrok.bat`

黑窗口会打印提示，然后停在一行等你输入：

```
Paste your authtoken:
```

把刚才复制的那串**粘贴**进去 —— 在黑窗口里，**粘贴是点鼠标右键**（部分系统 `Ctrl + V` 也行），
粘好了按**回车**。

看到下面这段就成功了：

```
========================================
  Done! ngrok.yml saved.
========================================
Press any key to continue . . .
```

按任意键关掉窗口。它会在这个文件夹里生成一个 `ngrok.yml`，里面存着你的 token
（这个文件已经被 `.gitignore` 排除，**不会上传到 GitHub**）。

#### ④ 万一出错了

| 现象 | 原因 / 怎么办 |
|---|---|
| 粘上去没反应，或者只粘了一半 | 黑窗口里用**鼠标右键**粘贴最稳，别用 `Ctrl + V` |
| 提示 `No input, exit.` | 什么都没粘就回车了。重新双击 `配置ngrok.bat` 再来一次 |
| 待会儿启动隧道报 `authtoken is invalid` | 复制的时候少了一位。回到第 ② 步重新复制一遍 |

### 3. 手机装 App

手机浏览器打开 👉 https://github.com/yy1234567890-09876543q/Elysia_dsh/releases/latest

下载 `Elysia_dsh-v1.0.apk` 装上。第一次装会提示「未知来源应用」，允许一下就行。

> 💡 手机上打不开 GitHub 的话，把 apk 用微信/QQ/数据线传到手机再点开也一样。

## 二、认证（**必看**，不配连不上）

DSH 默认就带认证：`dsh web` 启动时会打印一条**带令牌的地址**，App 拿它去换一张
**30 天有效**的签名凭证，之后所有请求都要带上这张凭证。

App 原生支持这套流程，**所以你不需要再装 `dsh-local-no-auth`
那种「关掉认证」的插件**。

### 怎么用（超简单）

设置页里**地址和令牌是分开的两个框**（默认都打码，右边「显示」可以看一眼）：

| 框 | 填什么 |
|---|---|
| **DSH 服务地址** | 只填域名那一段，比如 `https://xxxx.ngrok-free.dev` |
| **访问令牌** | 把 `dsh web` 打印的**整条地址**直接粘进来就行（App 只取 `?token=` 那部分，自动套到上面的地址上）|

填好点「**保存并连接**」。

App 会自动拿这个令牌去换一张 **30 天有效**的凭证，并且只把**干净的地址**存进历史 ——
历史里不会塞满一次性令牌，认证也不用每次都重来。

设置页会显示认证状态：

| 状态 | 含义 |
|---|---|
| 🟢 已认证 | 一切正常 |
| 🟡 服务器不要求认证 | 服务端没开认证 —— **去检查一下是不是装过「关认证」插件** |
| 🔴 需要令牌 | 缺凭证 —— 把令牌重新粘一次 |
| ⚪ 连不上 | 服务器没起来 / 地址填错了 |

> 💡 令牌每次 `dsh web` 重启都会变，但**换来的凭证 30 天有效**，
> 所以正常情况下一个月才需要重粘一次。
> 换令牌时**只要填令牌框**，地址栏里原来的域名不用重填。

### 强烈建议：让 DSH 保持认证开启

DSH 自带的认证就是最好的一层防护，**不要为了图方便装「关掉认证」的插件**。
如果已经装过类似 `dsh-local-no-auth` 的东西，建议卸掉：

```bash
dsh plugin --profile web remove dsh-local-no-auth
```

然后**重启 `dsh web`**，按上面的步骤在 App 里重新粘一次令牌即可。

## 三、连上它：ngrok 隧道（每次用，三步走）

### 第 1 步：启动 DSH 服务

在电脑上开个黑窗口（`Win + R` → `cmd` → 回车），跑：

```bash
dsh web
```

正常会看到 `dsh web: http://127.0.0.1:3080/?token=...`。
**这个黑窗口不要关**，关了 AI 就下班了。

> 📋 把这一整行（带 `?token=` 的地址）复制下来，第 3 步要用。
> 在 `cmd` 里选中文字是**按住鼠标左键拖**，选好按回车就复制了。

### 第 2 步：启动 ngrok 隧道

**双击项目里的 `启动隧道.bat`**，会弹出一个新的黑窗口，长这样：

```
========================================
  DShChat Tunnel
  Local: http://127.0.0.1:3080
========================================

Copy the https URL from "Forwarding" line below,
paste it into the app settings.

Forwarding   https://xxxx-xx-xx-xx-xx.ngrok-free.dev -> http://localhost:3080
```

**`Forwarding` 那一行里 `https://` 开头的那个地址，就是你要的地址**，把它复制下来。

三件要注意的事：

- 🪟 这个黑窗口**不能关**（关掉隧道就断了），可以最小化到任务栏。
- 🔁 免费版 ngrok **每次重启地址都不一样**，所以每次都要重新复制粘贴到 App 里。
  想要一个永远不变的地址，得买 ngrok 付费版。
- 🛡️ 隧道脚本里带了 `--host-header=rewrite`，**这是必须的**，别自己手敲命令去掉它 ——
  它把 Host 改写成 `localhost:3080`，DSH 的防 DNS 重绑定闸门才会放行。

> ⚠️ **开隧道之前，请确认「二、认证」已经配好**，否则等于把电脑的控制权公开到互联网上。

### 第 3 步：把地址填进 App

1. 打开手机上的 **Elysia_dsh** → 右上角 **⚙️ 设置**
2. 找到「**连接**」那一栏，里面有两个框，两个都要填：

   | 框 | 填什么 | 举例 |
   |---|---|---|
   | **DSH 服务地址** | 第 2 步复制的那个 ngrok 地址（**结尾不要带 `/`**） | `https://xxxx.ngrok-free.dev` |
   | **访问令牌** | 第 1 步复制的**整条带 `?token=` 的地址**，原样粘进去 | `http://127.0.0.1:3080/?token=xxxxxxxx` |

   > 两个框默认都打码显示（像 `••••••`），点右边的「**显示**」可以看一眼确认没粘错。
   > 粘错了就点「显示」检查一下，再点一次「显示」就重新打码。

3. 点最下面「**保存并连接**」
4. 回到主界面，顶部会自动刷出会话列表 → 点一个会话进去就能聊天了
5. 第一次用建议点右上角 **＋** 新建一个自己的会话，名字随便起

> 看到设置页显示 🟢 **已认证** 就说明全通了。
> 显示 🔴 或者 ⚪ 的话，翻到「五、常见问题」找对应那一条。

## 五、常见问题

**Q: 设置页显示 ⚪ 连不上 / 打开 App 一片空白**
- 确认电脑上 `dsh web` 那个黑窗口还开着（关了服务就没了）
- 确认 `启动隧道.bat` 那个黑窗口也还开着
- 确认「DSH 服务地址」那一栏**结尾没有多打一个 `/`**
- ngrok 免费版地址每次重启都会变，去第 2 步重新复制一次最新地址

**Q: 手机浏览器能打开地址，App 却连不上**
- 把地址栏里的地址和 ngrok 窗口里的 `Forwarding` 那行**逐字对一遍**，
  常见错法是少了 `https://` 或者多复制了后面的 `-> http://localhost:3080`
- 确认用的是 `https://` 开头（不是 `http://`）

**Q: 提示「服务器要求认证（401）」/ 界面显示 🔴 需要令牌**
- 说明服务端开着认证，但 App 手里没有凭证
- 去设置里把 `dsh web` 打印的**整条地址（带 `?token=`）**重新粘一次就好
- 每次 `dsh web` 重启令牌都会变，但换来的凭证能用 30 天

**Q: 显示 🟡 服务器不要求认证**
- 服务端没开认证（多半装了 `dsh-local-no-auth` 之类的插件）
- **如果隧道还开着，请立刻关掉隧道 + 卸掉插件** —— 见开头的「⚠️ 安全警告」

**Q: 启动隧道报错 `authtoken is invalid` / `ERR_NGROK_xxx`**
- 重新双击 `配置ngrok.bat`，把 authtoken 重新粘贴一次（注意别少字符）
- `ERR_NGROK_108` 之类提示「会话数超了」：免费版同时只能开一条隧道，把别的 ngrok 窗口关掉

**Q: 发消息没反应**
- 检查地址和令牌是不是都填了
- 检查 ngrok 隧道还活着（那个黑窗口没关）

**Q: 通知没声音**
- 手机设置 → 应用 → Elysia_dsh → 通知 → DSH 任务完成 → 声音，确保开了
- 确认手机没开静音/勿扰模式

**Q: 发消息的时候状态栏多了一条「正在等待回复…」通知**
- 这是正常的，别关它。发送期间 App 会挂一个**数据同步前台服务**，
  系统才不会在切后台时冻结进程，回复完成时通知才弹得出来。
- 回复结束（或出错）它会自动消失，平时不会常驻。

**Q: 切后台 / 锁屏之后就不提醒了**
- 先确认通知权限开着，然后看设置里「只在后台提醒」是不是被打开了
- 手机厂商的省电策略也可能干掉后台：设置 → 电池 → 找到 Elysia_dsh → 选「不限制」

**Q: ngrok 地址每次都变？**
- 免费版每次启动地址都不一样，每次都要重新复制粘贴
- 想要固定地址得买 ngrok 付费版
